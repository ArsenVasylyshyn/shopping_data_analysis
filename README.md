# 🛒 Shopping Data Analysis

Этот скрипт позволяет проанализировать список покупок по следующим критериям:

- Общая выручка
- Товары, сгруппированные по категориям
- Список дорогих покупок (выше определённой цены)
- Средняя цена товаров в каждой категории
- Категория с наибольшим количеством проданных товаров

## 📦 Структура данных

Входные данные — следующего формата:

```python
purchases = [
    {"item": "apple", "category": "fruit", "price": 1.2, "quantity": 10},
    {"item": "banana", "category": "fruit", "price": 0.5, "quantity": 5},
    {"item": "milk", "category": "dairy", "price": 1.5, "quantity": 2},
    {"item": "bread", "category": "bakery", "price": 2.0, "quantity": 3},
]
```
